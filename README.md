## 📚 Documentation

- [`docs/System-Contract.md`](docs/System-Contract.md) — the normative contract: public API, limits,
  exception taxonomy, wire format down to the byte, and the supported types. It is exhaustive by
  design: a test, or a second implementation, can be written from it without reading the source.
- [`docs/Architecture-Audit.md`](docs/Architecture-Audit.md) — why the architecture looks the way it
  does: the audit that produced it, the alternatives rejected, and the invariants it guarantees.
- [`docs/QA-Plan.md`](docs/QA-Plan.md), [`docs/Benchmark-Plan.md`](docs/Benchmark-Plan.md) — test and
  benchmark plans.
- [`docs/audit/`](docs/audit) — historical record of the security audit that drove the current design.
